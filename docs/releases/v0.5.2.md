# Pi-Vis v0.5.2

## Highlights

- Added interactive direct Shell Turns for `!` and `!!` commands, with a live PTY-backed terminal, interactive input, and normalized output in the transcript.
- Made Shell Turn context explicit: `!` keeps the command and output eligible for Pi context, while `!!` keeps the turn visible and persisted without adding it to Pi context.
- Improved session reliability across runtime recovery, renderer reattachment, session switching, navigation, and lifecycle transitions.
- Added persistent, rotating local crash diagnostics for main-process, renderer, Electron child-process, and SDK-host failures.
- Updated the bundled Pi runtime to 0.82.1.
- Improved model selection by preserving and clearly identifying saved models that are no longer available.

## Fixes and polish

- Improved shell draft editing, selection, caret synchronization, cancellation, and terminal reattachment.
- Refreshed changed-file counts after direct shell commands and hardened packaged native PTY verification.
- Bounded retained navigation state and strengthened recovery handling to prevent stale or duplicate runtime actions.

## Upgrade notes

- No manual action required. Existing sessions and saved state continue to work normally.

## Assets

- macOS Apple Silicon ZIP for installer/auto-update
- macOS Apple Silicon DMG for manual install
