# Pi-Vis v0.5.3

## Highlights

- Updated the bundled Pi runtime to 0.83.0, including improved provider authentication, model scoping, streamed usage, session navigation, and direct `user_bash` extension integration.
- Added three Cendre themes: Hard, Medium, and Soft. Pi-Vis now includes twelve built-in color schemes.
- Strengthened session reliability across runtime recovery, replacement, navigation, cancellation, queue custody, and Shell Turn reattachment.
- Improved transcript rendering for long histories and live streams, Compact activity grouping, extension-renderer visibility, and selection-aware Markdown clipboard copying.
- Hardened queued-message operations so moves and removals are exposed only when the host can prove they are safe, while cancelled or interrupted drafts remain recoverable.

## Fixes and polish

- Improved provider sign-in flows so the browser action remains available while a prompt or device-code response is pending.
- Preserved tree-viewer selection when filtering or folding changes which rows are visible.
- Fixed syntax highlighting for changed diff lines and corrected settings backdrop/scrim behavior.
- Improved context-meter interaction and sidebar working-indicator performance.
- A shell command cancelled before execution now preserves its current draft.

## Upgrade notes

- No manual action required. Existing sessions and saved state continue to work normally. New Cendre themes are available in Settings.

## Assets

- macOS Apple Silicon ZIP for installer/auto-update
- macOS Apple Silicon DMG for manual install
