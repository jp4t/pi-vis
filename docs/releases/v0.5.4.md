# Pi-Vis v0.5.4

## Highlights

- Improved IPC scalability for long streamed responses. Assistant message updates now travel as incremental events while the host maintains a compact checkpoint for renderer reattachment, reducing redundant traffic as responses grow.
- Strengthened session recovery with up to three short, backoff-delayed SDK-host restart attempts within a 30-second crash window, while preserving validated editor drafts and conflict state across failed replacement attempts.
- Improved transcript and panel reattachment so covered streaming output is restored without duplicating token deltas, and high-volume presentation traffic remains bounded.

## Fixes and polish

- Added explicit IPC backpressure diagnostics and a bounded host queue that fails safely rather than dropping sequenced authority updates.
- Fixed panel sizing and repaint coordination after terminal content changes, reducing resize loops and stale measurements.
- Expanded Electron, render, session, and streaming checkpoint coverage for recovery, attachment, and high-volume IPC paths.

## Upgrade notes

- No manual action required. Existing sessions and saved state continue to work normally.

## Assets

- macOS Apple Silicon ZIP for installer/auto-update
- macOS Apple Silicon DMG for manual install
